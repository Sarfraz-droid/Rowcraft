What is Rowcraft?

Rowcraft is an open source desktop database workbench built with Rust, Tauri, and React. It combines a database explorer, SQL console, results grid, and a headless CLI.

How do I connect my own databases?

Install the desktop app to add your database connections. The preview above is a screenshot of Rowcraft; database connections and queries run in the desktop app.

Which operating systems can I build for?

Rowcraft uses Tauri for macOS, Windows, and Linux. Building from source requires Rust, Node 22.12+, pnpm 11, and the Tauri prerequisites for your platform.

How does Rowcraft handle database credentials?

Connection settings reference environment variable names for passwords. Credentials stay in your environment. SSH tunnels are handled by the Rust engine, with explicit host-key verification.

Build Rowcraft from source

To build the desktop app, install Rust, Node 24, pnpm 11, and your platform’s Tauri prerequisites. From your Rowcraft source checkout, run:

pnpm --dir apps/dg-desktop install --frozen-lockfile
pnpm --dir apps/dg-desktop installer

Find setup details and connector compatibility in the project README.
