Database compatibility & driver requirements

Native connectors include PostgreSQL, SQLite, MySQL, MariaDB, Redis, MongoDB, Cassandra, and more. Other databases connect through JDBC, requiring Java 11+ and vendor driver JARs. Support and live testing vary by connector; see the project README for the full status.

One 120-second capture after a 30-second warmup. Observed process trees only; external WebKit helpers are excluded, undercounting Rowcraft’s total memory. Memory values are not total app footprints. Relative CPU compares average idle CPU usage, not query or startup speed.

Test conditions & results

Captured October 18, 2026 on macOS 26.6.2 (ARM64, 12 logical CPUs), with 98 samples over 120.04 seconds. Both app instances were sampled on the same Mac. Values show average resident set size (RSS), weighted by sampling interval, in MiB (1 MiB = 1,048,576 bytes).

Memory is the sum of RSS for each main process and observed descendants. Shared pages may be counted more than once; compressed or swapped allocations are not fully represented. No additional helper processes were attributed. Helpers launched outside the process tree, including macOS-managed WebKit helpers, are not included. This is not macOS physical footprint or JVM heap size. Relative CPU divides each app’s average CPU usage by DataGrip’s average and multiplies by 100; these index values are not percentages of system CPU. Raw CPU is calculated from elapsed process CPU time, with 100% representing one logical CPU fully occupied. Results vary with your workload and system.

What is Rowcraft?

Rowcraft is an open source desktop database workbench built with Rust, Tauri, and React. It combines a database explorer, SQL console, results grid, and a headless CLI.

How do I connect my own databases?

Install the desktop app to add your database connections. The preview above is a screenshot of Rowcraft; database connections and queries run in the desktop app.

Which operating systems can I build for?

Rowcraft uses Tauri for macOS, Windows, and Linux. Building from source requires Rust, Node 22.12+, pnpm 11, and the Tauri prerequisites for your platform.

How does Rowcraft handle database credentials?

Connection settings reference environment variable names for passwords. Credentials stay in your environment. SSH tunnels are handled by the Rust engine, with explicit host-key verification.

Build Rowcraft from source

To build the desktop app, install Rust, Node 24, pnpm 11, and your platform’s Tauri prerequisites. From your Rowcraft source checkout, run:

pnpm --dir apps/dg-desktop install --frozen-lockfile
pnpm --dir apps/dg-desktop installer

Find setup details and connector compatibility in the project README.
