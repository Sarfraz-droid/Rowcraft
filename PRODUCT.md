## Platform
web

## Users
Developers exploring, querying, and managing databases from a desktop workbench.

## Product Purpose
Rowcraft is an open source database app with a Rust engine, Tauri desktop UI, and headless CLI. The landing page should encourage visitors to try a demonstration and download the app.

## Capabilities and Constraints
SQL console, database explorer, result grid, export/import, schema exploration, custom drivers, and SSH tunnels. Native connectors and JDBC bridge; JDBC requires vendor JARs and Java. The browser demo is illustrative and does not connect to real databases. No public repository URL or release download URLs are configured in this checkout.

## Brand Commitments
Rowcraft name and existing brand marks. User requests a dark landing page similar to samples/arccheo.framer.ai.

## Evidence on Hand
README.md, SPEC.md, desktop source, and apps/rowcraft-desktop/public/brand. No customer testimonials or performance benchmarks supplied.
